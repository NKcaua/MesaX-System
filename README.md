# \# 🍽️ MesaX System — Sistema de Gerenciamento para Restaurantes

# 

# O \*\*MesaX System\*\* é um sistema desenvolvido com o objetivo de facilitar e organizar as atividades de gerenciamento de um restaurante. A plataforma centraliza operações como controle de mesas, registro de pedidos, acompanhamento do preparo na cozinha, gerenciamento de produtos e fechamento de contas.

# 

# O projeto foi desenvolvido com foco em tornar os processos mais organizados, reduzir falhas no atendimento e facilitar o acesso às informações do estabelecimento.

# 

# \## 🚀 Funcionalidades

# 

# \- \*\*Controle de Mesas:\*\* gerenciamento das mesas do restaurante e acompanhamento de sua situação.

# \- \*\*Gerenciamento de Pedidos:\*\* registro e acompanhamento dos pedidos realizados.

# \- \*\*Painel da Cozinha:\*\* visualização dos pedidos e atualização de seus status durante o preparo.

# \- \*\*Gerenciamento de Produtos:\*\* consulta, edição de informações e controle de disponibilidade dos produtos.

# \- \*\*Controle de Contas:\*\* acompanhamento dos valores consumidos em cada mesa.

# \- \*\*Registro de Pagamentos:\*\* registro de pagamentos por diferentes métodos, incluindo dinheiro, Pix e cartão.

# \- \*\*Controle de Acesso:\*\* autenticação de usuários e permissões de acordo com seu perfil.

# \- \*\*Painel do Gerente:\*\* consulta de informações administrativas, histórico de pedidos e relatórios de vendas.

#

# \## 🏗️ Estrutura do Projeto

# 

# O sistema está organizado em duas partes principais:

# 

# \- \*\*Front-end:\*\* responsável pela interface visual e pela interação dos usuários com o sistema.

# \- \*\*Back-end:\*\* responsável pelas regras de negócio, processamento das solicitações e comunicação com o banco de dados.

# 

# O banco de dados SQLite é utilizado para armazenar as informações do sistema.
